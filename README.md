# wbr_chassis
STM32H723 code for wheel-balanced robot chassis
## 约定
### 1. 绝对坐标系基准 (Absolute Coordinate System)

模型采用严格的标准右手直角坐标系：

* **X 轴正方向**：机器人正前方（前进方向）。
* **Z 轴正方向**：竖直向上（与重力方向严格相反）。
* **Y 轴正方向**：机器人正左方。
* **旋转正方向**：右手螺旋定则（例如：俯视 XY 平面，逆时针转动为正）。

---

### 2. 状态变量正方向约定 (State Variables Polarity)

状态向量 $X = [X_b^h, \dot{X}_b^h, \phi, \dot{\phi}, \theta_l, \dot{\theta}_l, \theta_r, \dot{\theta}_r, \theta_b, \dot{\theta}_b]^T$

| 状态变量 | 物理含义 | 正方向 (+ > 0) 的绝对物理姿态 | 实车传感器映射提示 |
| --- | --- | --- | --- |
| **$X_b^h$** | 机体平动位移 | 机体偏离初始原点**向前**。 | 里程计向前累加为正。 |
| **$\phi$** | 偏航角 (Yaw) | 俯视机体，**向左偏航（逆时针旋转）**。 | 陀螺仪 Yaw 轴左转为正。 |
| **$\theta_l, \theta_r$** | 左右腿摆杆角 | 髋关节处于轮轴正前方，即**腿向后摆**。 | 腿伸直垂直向下为 0°，轮子在机身后方为正。 |
| **$\theta_b$** | 机体俯仰角 (Pitch) | 质心越过髋关节向前倾，即**机体低头/前倾**。 | 逆时针旋转为正。 |

---

### 3. 控制力矩正方向约定 (Control Inputs Polarity)

控制向量 $U = [T_{wl \to l}, T_{wr \to r}, T_{l \to b}, T_{r \to b}]^T$

| 控制变量 | 作用对象 | 正方向 (+ > 0) 的绝对物理响应 | 实车电机发力映射提示 |
| --- | --- | --- | --- |
| **$T_{wl \to l}, T_{wr \to r}$** | 左右轮毂电机 | 驱动轮子**向前滚动**，推动机体加速前进。 | 给定正向电流指令，轮子向前转。 |
| **$T_{l \to b}, T_{r \to b}$** | 左右髋关节电机 | 驱动机身**向后仰（抬头）**，同时反作用力驱使腿部**向前摆**。 | 给定正向电流指令，大腿相对机身向前踢出。 |

---

### 4. 控制器响应验证 (Controller Response Verification)
根据控制律 **$U = -KX$**, **$X=X_{obs}-X_{ref}$**

| 状态偏差 ($X > 0$) | 主要期望响应 ($U$) | 对应K矩阵符号 ($K$) |
| --- | --- | --- |
| **$X_1$**: $X_b^h > 0$ (机体前移) | **$T_{wl \to l} < 0,\; T_{wr \to r} < 0$** | **$K_{1,1} > 0,\; K_{2,1} > 0$** |
| **$X_2$**: $\dot{X}_b^h > 0$ (向前线速度) | **$T_{wl \to l} < 0,\; T_{wr \to r} < 0$** | **$K_{1,2} > 0,\; K_{2,2} > 0$** |
| **$X_3$**: $\phi > 0$ (向左偏航) | **$T_{wl \to l} > 0,\; T_{wr \to r} < 0$** | **$K_{1,3} < 0,\; K_{2,3} > 0$** |
| **$X_4$**: $\dot{\phi} > 0$ (向左偏航速度) | **$T_{wl \to l} > 0,\; T_{wr \to r} < 0$** | **$K_{1,4} < 0,\; K_{2,4} > 0$** |
| **$X_5$**: $\theta_l > 0$ (左腿后摆) | **$T_{l \to b} > 0$** | **$K_{3,5} < 0$** |
| **$X_6$**: $\dot{\theta}_l > 0$ (左腿后摆速度) | **$T_{l \to b} > 0$** | **$K_{3,6} < 0$** |
| **$X_7$**: $\theta_r > 0$ (右腿后摆) | **$T_{r \to b} > 0$** | **$K_{4,7} < 0$** |
| **$X_8$**: $\dot{\theta}_r > 0$ (右腿后摆速度) | **$T_{r \to b} > 0$** | **$K_{4,8} < 0$** |
| **$X_9$**: $\theta_b > 0$ (机体前倾) | **$T_{wl \to l} > 0,\; T_{wr \to r} > 0$**<br>**$T_{l \to b} < 0,\; T_{r \to b} < 0$** | **$K_{1,9} < 0,\; K_{2,9} < 0$**<br>**$K_{3,9} > 0,\; K_{4,9} > 0$** |
| **$X_{10}$**: $\dot{\theta}_b > 0$ (前倾角速度) | **$T_{wl \to l} > 0,\; T_{wr \to r} > 0$**<br>**$T_{l \to b} < 0,\; T_{r \to b} < 0$** | **$K_{1,10} < 0,\; K_{2,10} < 0$**<br>**$K_{3,10} > 0,\; K_{4,10} > 0$** |
